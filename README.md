# AeroTrack - Training Records Management System

A comprehensive system for managing aviation training progress, digital records, certificates, licenses, and exam history.

## Features

- 📚 **Training Progress Tracking** - Monitor hours and completion status
- 📄 **Digital Training Records** - Centralized student information storage
- 🏆 **Certificate & License Tracking** - Manage expiration dates and status
- 📁 **Document Storage** - Upload and organize training documents
- 📝 **Exam & Checkride History** - Track all exams and checkride results

## Tech Stack

- **Frontend**: React with Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: SQLite (can upgrade to PostgreSQL)
- **Authentication**: JWT
